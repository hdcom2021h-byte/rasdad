# تشغيل موقع رصداد

شغّل `python server.py` أو ملف `start.ps1` ثم افتح http://127.0.0.1:8000. استخدم هذا الرابط بدل فتح ملفات HTML مباشرة أو عبر Live Server حتى تعمل الزيارات والتقييمات والنماذج.
يتطلب Python 3.10 أو أحدث، دون مكتبات إضافية.

تعرض نافذة التشغيل مفتاح الإدارة. افتح `/admin.html` وأدخل المفتاح للاطلاع على أسماء وبيانات أصحاب الاستفسارات والطلبات. يمكن تثبيت المفتاح عبر متغير البيئة `RASDAD_ADMIN_TOKEN`؛ وإلا يُنشأ مفتاح جديد في كل تشغيل. لا يُحفظ المفتاح في المتصفح.

تُحفظ البيانات في `data/rasdad.sqlite3`. انسخ الملف احتياطيًا عند توقف الخادم. يمكن تغيير مساره عبر `RASDAD_DB`. ملفات البيانات والخادم غير متاحة عبر خادم الموقع.

للنشر يلزم تشغيل خدمة Python مع قرص دائم وخادم عكسي يدعم HTTPS، وضبط `RASDAD_ADMIN_TOKEN` بمفتاح قوي. يمكن ضبط `PORT` و`RASDAD_HOST` حسب الاستضافة. الاستضافة الثابتة أو Live Server يعرضان الصفحات فقط؛ الحفظ والإحصاءات يحتاجان الخادم المرفق. ضع حدودًا لمعدل الطلبات على الخادم العكسي عند النشر العام.

عداد الزوار يبدأ من التشغيل الفعلي، ويعد المتصفحات باستخدام ملف تعريف ارتباط لمدة سنة؛ ليس عدد الأشخاص المؤكد ولا يسترجع الزيارات السابقة. حذف ملفات الارتباط أو تغيير الجهاز قد يحتسب زيارة جديدة. لا تُعرض هويات الزوار للعموم. ينشر المستخدم اسمه وتقييمه عبر زر «نشر التقييم»، دون تعليق أو حقول إضافية. يُحدّث تقييم المتصفح نفسه عند إعادة الإرسال. تظهر آخر 50 مراجعة مع متوسط جميع التقييمات.

النماذج تحفظ الاستفسارات والطلبات في الإدارة. زر واتساب يفتح رسالة جاهزة فقط؛ لا يمكن تأكيد إرسالها أو هوية من يفتح الرابط عبر الموقع.

بيانات أصحاب الطلبات والاستفسارات تظهر للإدارة فقط. أُلغي نشر أسمائهم وخيار الموافقة من النماذج. لا تُرسل التعليقات القديمة إلى الواجهة العامة.
